# Консольная мини-игра "Виселица"

## Описание

Консольная мини-игра *"Виселица"* - игра на угадывание слов с взаимодействием с пользователем через консоль. Игра поддерживает графический интерфейс, подсказки в виде отсутствующих, ранее введённых слов, выбор как русских, так и английских слов и предоставляет полную обратную связь, делая взаимодействие простым и понятным.

## Играть

1. Запустите игру.
2. Выберите категорию слов (Rus, Eng).
3. Вводите предполагаемые буквы, пока не угадаете слово или пока не проиграете.

## Установка и запуск

1. Скачайте следующие файлы:
   - `main.py`
   - `utils.py`
   - `english_words.txt`
   - `russian_words.txt`

2. Запустите файл `main.py`

## Требования к установке

- на компьтере должен быть установлен Python;
- файлы должны располагаться в одной директории.
